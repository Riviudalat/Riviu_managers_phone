# Claude Code exports

- `chat-latest.md` — đoạn chat Claude Code mới nhất (đã làm sạch, dễ đọc)
- `chat-latest.messages.jsonl` — cùng nội dung dạng JSONL
- `plan-latest.md` — plan Claude Code gắn với session đó (nếu có)

Session gốc nằm ở `~/.claude/projects/...` (file raw ~48MB, không đưa vào repo).
